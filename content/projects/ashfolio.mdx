## Overview

The site you're looking at right now. A developer portfolio built to showcase my work with the same care I put into the projects themselves.

## Technical Highlights

- **MDX content pipeline** with server-rendered syntax highlighting via Shiki
- **OKLCH color system** with dark/light theme support
- **Ember particle effects** adapted from Hibana's particle system
- **Perfect Lighthouse scores** — 100/100/100/100
- **Full SEO** — sitemap, RSS feed, dynamic OG images, JSON-LD structured data

## Stack

- Next.js 16 (App Router, React 19)
- Tailwind CSS 4 + shadcn/ui
- MDX with next-mdx-remote
- Framer Motion
- Vercel
